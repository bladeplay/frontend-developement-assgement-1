======================================================
1. OVERVIEW
======================================================

This project is a responsive personal portfolio website built
with HTML5, CSS3, and vanilla JavaScript. It features a dark
OLED-themed design with a fixed navigation bar, hero section,
about section, projects grid, contact section, and footer.

======================================================
2. TECHNOLOGIES USED
======================================================

- HTML5: Semantic markup (nav, section, footer, ul, li)
- CSS3: Custom properties (variables), Flexbox, Grid
  - backdrop-filter (with -webkit- prefix for Safari)
  - CSS variables for theming
  - Responsive grid layout for projects
- JavaScript: Referenced for project descriptions (CLP clock,
  Kaleidoscope Drawer, T-Rex Runner Game)

======================================================
3. DESIGN THEME
======================================================

Color scheme (OLED dark theme):

  --primary:        #5865f2  (Blurple)
  --primary-hover:  #4752c4  (Darker Blurple)
  --bg:             #000000  (Pure Black)
  --card-bg:        #111214  (Dark Container)
  --card-border:    #1e1f22  (Border Color)
  --text:           #f2f3f5  (Light Text)
  --text-muted:     #949ba4  (Muted Text)

======================================================
4. SECTIONS
======================================================

4.1 Navigation (nav)
  - Fixed at top of viewport
  - Semi-transparent dark background with blur effect
  - Links: About, Projects, Contact

4.2 Hero (section#hero)
  - Full viewport height (min-height: 80vh)
  - Displays name, tagline, and call-to-action button
  - Flexbox columnar layout, left-aligned content

4.3 About (section#about)
  - Student metadata (Roll No, Batch)
  - Short bio paragraph
  - Skills list (HTML5, CSS3, JavaScript, DOM, Git, C, Python)

4.4 Projects (section#projects)
  - Responsive grid (auto-fit, minmax 280px)
  - Three project cards with descriptions and tech tags:
    a) CLP (Clock App) - JavaScript, HTML, CSS
    b) Kaleidoscope Drawer - JavaScript, CSS Animations
    c) T-Rex Runner Game - JavaScript, Game Loop
  - Each card has a GitHub link (target=_blank)

4.5 Contact (section#contact)
  - Email link (mailto:)
  - GitHub profile link (target=_blank)

4.6 Footer
  - Copyright notice with roll number and batch
  - Download button for this documentation file

======================================================
5. SECURITY NOTES
======================================================

- All external links use target="_blank" with
  rel="noopener noreferrer" to prevent reverse tab-nabbing.
- Internal anchor links (#about, #projects, #contact) use
  standard href navigation without security concerns.

======================================================
6. RESPONSIVENESS
======================================================

- The main content is constrained to max-width: 1000px
  and centered with margin: 0 auto.
- The projects grid uses CSS Grid with auto-fit and minmax
  to adapt to different screen sizes.
- The skills list uses Flexbox with flex-wrap for responsive
  tag layout.
- The nav uses Flexbox for space-between layout.
